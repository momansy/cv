## How to add your personal photo
1. Open the `assets` folder.
2. Add your photo.
3. Rename it exactly:

```text
profile.jpg
```

Recommended:
- Square image, for example 1080x1080.
- JPG format.
- Face centered.

## How to replace the PDF CV
Replace this file:

```text
assets/Mohamed_Ayman_Elmansy_CV.pdf
```

Keep the same filename so the download buttons continue working.
